nocturne but better 2.4.0 (formerly nocturne flat scroll)
windows x64 | steam nocturne 1.0.0 | tested steam build 25460029
works with bepinex 6 (bundled) or melonloader 0.7.3 and newer (not bundled)

install
1. install nocturne through steam on the other pc, then close the game.
2. extract this entire zip to a folder. do not run it from inside the zip.
3. double-click install.cmd. it finds the steam game folder automatically.
   if asked for a folder, use steam > nocturne > manage > browse local files
   and paste the folder containing nocturne.exe.
4. start nocturne normally through steam. the first launch can take longer
   while the loader prepares files; internet access may be needed.
5. open options > gameplay and set:
   note scrolling   - default, 2d downscroll, or 2d upscroll
   receptor height  - -10% to +30%; moves the receptors in from their edge
                      of the screen in both 2d modes (0% = original spot)
   note size        - 50% to 150%; notes and receptors in both 2d modes
   lane spacing     - 60% to 150%; how far apart the 2d lanes are
   note skin        - default bars, circles, or arrows
   note flares      - on or off; the burst when you hit or hold a note
                      (mine explosions always show)
   timing bar       - off or on; shows how early (rabbit) or late (turtle)
                      each hit was, next to the receptors
   timing bar position - 2d upscroll only: below enemy (under the receptors)
                      or above enemy (along the top of the screen)
   enemy attack opacity - 0% to 100%; how visible the enemy stays while it
                      attacks (100% = unchanged)
   the game's own note colors row gets a preview under it, with a red mine
   next to your notes so you can spot palettes that look like it.
6. in options > audio, under sound effects:
   hit sound        - off or on; a short tick when you hit a note
   hit sound volume - 5% to 100%; the game's sound effect volumes apply too
   miss sound       - on or off; the same setting as note miss sounds
   miss sound volume - 10% to 300%; 100% is the game's normal level

which loader gets used
- melonloader 0.7.3 or newer installed and turned on: the mod goes into mods.
- no melonloader: the bundled bepinex loader is added where missing and the
  plugin goes into bepinex\plugins.
only one copy runs at a time. to switch loaders, run install.cmd again; it
disables the copy for the other loader. do not keep bepinex and melonloader
in the same game folder, because only one of them can start.

the flat modes include compact, vertical health/energy bars. new
alt, tab, and the windows key no longer start a battle at "press any key".
any other key or a controller button still does.

installations start on default, 0%, 100% size and spacing, default skin,
note flares on, timing bar off and below the enemy, enemy attack opacity
100%, hit sound off at 80%, and miss sound volume 100%. your selections
are saved on that pc. the title screen and the intro's logo card
read "nocturne but better, by terrydavisgaming".

optional fullscreen flicker fix
if you have the flickering black bars, close nocturne and double-click
enable-fullscreen-fix.cmd. this applies the same directx 11 preference used
on the original pc. restore-fullscreen-fix.cmd reverses that change.
the scrolling mod works independently of this fix.

remove
close nocturne, then run uninstall.cmd to disable this mod for both loaders.
run restore-fullscreen-fix.cmd too if you enabled the display fix.
uninstall keeps the loaders because other mods may use them. saves, scores,
other mods, and saved scrolling preferences are left in place.

if something does not work
- access denied: right-click the relevant .cmd and run as administrator.
- wrong build or unknown files: stop and use a package updated for your
  game version. the installer refuses unknown game files on purpose.
- an existing bepinex conflicts: this package needs bepinex il2cpp x64
  build 788. do not replace another mod setup without checking it first.
- melonloader too old: update it to 0.7.3 or newer, then run install.cmd.
- options rows missing: check bepinex\logoutput.log or
  melonloader\latest.log in the game folder. confirm the zip was fully
  extracted before running install.cmd.
- steam updates / verify integrity may remove the optional display patch.
  this package must be checked again after a game update.

share
send the original nocturne-flat-scroll-2.4.0-windows.zip to the other person
or device. they need their own installed copy of nocturne. the package
contains no game assets, game-generated assemblies, saves, or account data.
it does not support macos, linux, or steam deck through these installers.

contents
- payload: the bepinex plugin, the melonloader mod, and the unchanged
  official bepinex loader archive
- source: mod source and a project that builds either loader's dll
- third-party-notices.txt and licenses: loader notices and licenses
- third-party-source: source archives for the bundled lgpl components
- sha256sums.txt: package file integrity hashes
- technical-notes.md: compatibility, verification, and command-line use
